金融決鬥

金融知識卡牌對決

召喚交易怪獸，答對題目才能發動攻擊。

  1. 壹出牌從手牌選一張卡召喚
  2. 貳答題答對才能發動攻擊
  3. 參防禦對手攻擊時選卡抵擋

完整規則
  • 攻我方回合：從手牌選一張卡召喚。答對該卡屬性的題目，就能以攻擊力直擊對手資金。在難易度的速攻秒數內答對另加 300，連續答對 3 題起再加 500。
  • 守對手回合：對手召喚怪獸攻擊，選一張手牌防禦。答對時只承受「攻擊力 − 守備力」，守備力較高還會反彈；答錯則全額承受。
  • 技技能：每張卡都有專屬技能，例如刪去錯誤選項、減半傷害、反彈、回復資金或再攻擊一次。對手的卡在攻擊命中時也會發動技能，可在卡牌圖鑑查看全部。
  • 勝勝負：雙方資金各 10000，手牌 5 張，先歸零者落敗。答題限時依難易度而定，結算畫面會列出答錯題目與解析。

卡牌圖鑑

共 50 張卡，每個屬性 10 張（普通 3、稀有 3、超稀有 2、極稀有 2）。稀有度依星數分為普通、稀有、超稀有、極稀有。攻擊類技能在對手使用時，於攻擊命中你的時候同樣發動。

間隔複習

錯題本

對戰中答錯的題目會自動收進來。之後的對戰會優先穿插到期的錯題，也可以在這裡直接複習。答對一次升一階，第 1 階立即複習、第 2 階隔 1 天、第 3 階隔 3 天，第 3 階再答對就算掌握；答錯會退回第 1 階。

複習模式

題目與回報

題庫管理

內建題目加上你匯入的自訂題目會一起出題。卡牌屬性決定題目類別，卡牌星數決定難度（1–2 星出初階、3 星出中階、4 星出進階）。自訂題目存在這台裝置的瀏覽器裡。

匯入題目

貼上 JSON（可以是題目陣列，或 {"questions":[…]}），也可以選擇 .json 檔。相同 id 會覆蓋舊題。

題目格式

category 填 tech 技術分析、fund 基本面、deriv 衍生性商品、risk 風險管理、chips 籌碼與市場（也可直接寫中文類別名）。difficulty 為 1–3，answer 是正確選項的索引，從 0 開始。

{
  "questions": [
    {
      "id": "my-001",
      "category": "tech",
      "difficulty": 2,
      "q": "題目文字",
      "options": ["選項一", "選項二", "選項三", "選項四"],
      "answer": 0,
      "explain": "答對或答錯後顯示的解析"
    }
  ]
}

題目回報

答題時回報的問題存在這台裝置。按「複製全部回報」後貼給出題者（或貼給 Claude），就能逐題修正題庫。
